The MCP registry does not verify that an entry's repository.url belongs to the publisher. We run that comparison on every weekly sweep. Paste a repository and see what the latest snapshot says.

Accepts https://github.com/owner/name, owner/name, or an io.github.owner/name registry name.

Method, the full 100-row ranking, and what each label means: MCP Server Rankings 2026.

This page reads two static files and nothing else — index.json for the labels and totals, then one shard such as /data/mcp/ownership/by-repo/m.json. Both are free to query directly. Attribution terms travel inside the manifest.
