{%- comment -%} Declares the post's paired _data/{YYYY-MM-DD-slug}.json as a Dataset. Outputs nothing when the data file is missing, and nothing for drafts — the same gate _plugins/data_publisher.rb applies, so the schema never points at a dataset URL that is not live. `citation` carries the data file's primary_sources, so every claim is tied to its origin in the machine layer even before a reader reaches the body. `license` is deliberately NOT declared (CLAUDE.md principle 2). Google lists it as recommended, not required; the schema is valid without it. Do not add. {%- endcomment -%} {%- unless page.path contains '_drafts' -%} {%- assign data_key = page.date | date: '%Y-%m-%d' | append: '-' | append: page.slug -%} {%- assign ds = site.data[data_key] -%} {%- if ds and ds.slug -%} {%- endif -%} {%- endunless -%}
