# Image Pack — best-llm-2026

## Codex 실행 지시

이 문서를 읽은 에이전트가 할 일은 하나다. 아래 "커버 생성 프롬프트" 블록 전체를
`$imagegen`에 그대로 넘겨 이미지를 생성하고 지정 경로에 저장한다.

- **반드시 `$imagegen`을 호출한다.** Python·SVG·PIL 등 코드로 도형을 그리지 않는다.
  코드로 그린 산출물은 즉시 폐기 대상이며, 검증 훅이 색상 수로 잡아낸다.
- 저장 경로: `/workspaces/ai-tech-blog/assets/img/posts/best-llm-2026-cover-raw.png`
- 프롬프트 문구를 요약·의역·보완하지 않는다. 블록 전체를 그대로 넘긴다.
- 이미지 크기는 프롬프트에 적힌 2048×1152로 요청한다. 1200×630은 gpt-image가
  생성할 수 없다(630이 16의 배수가 아님). 크롭은 이쪽에서 별도로 처리한다.

## 대상

- 슬러그: `best-llm-2026`
- 포맷: A (도구 비교) / 클러스터: `CLUSTER_LLM`
- 이미지 구성: **커버 1장, 본문 도형 0장**
- 클래스: **A (표지 이미지)** — `IMAGE_GUIDE.md` §1

### 근거 대응표가 없는 이유

클래스 A는 본문의 값을 주장하지 않는다. 대응시킬 값이 없으므로 표가 성립하지 않는다.
표를 쓰고 싶어진다면 그 커버가 값을 그리고 있다는 뜻이고, P6 위반이다.

본문의 비교 수치와 `Not published` 결측값은 전부 본문 표가 전달한다. 커버는
`og:image` 역할만 한다.

## 커버 생성 프롬프트

```text
PURPOSE: Editorial cover art for a technical blog post. Decorative only.
It must not depict data, and it does not need to relate to the article topic.

SUBJECT: A single thick plano-convex optical glass lens element, roughly the
size of a palm, standing upright on its edge on a dark matte stone surface.
Fine dust, micro-scratches and a chipped bevel on the polished glass.

SCENE: The lens is tilted a few degrees off vertical, catching the key light
through its body so it throws one soft continuous pool of light across the
stone in front of it.

COMPOSITION: Wide horizontal establishing shot. One dominant subject placed on
the left or right third, not dead center. Clear foreground-to-background
separation with real depth. Keep the outer 8% of the top and bottom edges free
of critical detail — the frame is cropped to 1.91:1 afterwards.

STYLE: High-end technical magazine cover art. Photographic realism with an
editorial, restrained mood. Tactile real-world materials with visible surface
texture — machined metal, glass, stone, paper, fabric. Shallow depth of field.
Single subject, generous empty space, quiet and precise rather than busy.

LIGHTING & COLOR: Deep navy base environment (#0F172A). Cool cyan key light
(#38BDF8) raking from one side; warm amber rim light (#F59E0B) from the
opposite edge. Strong directional light with soft falloff. No flat ambient
fill, no uniform studio lighting.

AVOID: text, letters, numbers, captions, watermarks, logos, brand marks,
charts, graphs, axes, bars, gauges, readable scales or dials, UI screenshots,
app windows, code editors, robots, humanoids, androids, human faces, hands,
brains, glowing orbs, circuit-board motifs, holographic HUD overlays, neon
cyberpunk cliché, stock-photo business people, collage, split panels, grids of
thumbnails, borders, frames, vignette.

ASPECT RATIO: 2048x1152

MUST KEEP: Exactly one lens element — no row, no set, nothing countable.
Consistent light direction across the whole frame. Large areas of unbroken dark
background. The cast light stays one continuous pool — no separate bands, no
rainbow, no spectrum split. Nothing that could be read as a measurement.
```

## 반입 후 처리 (Claude Code 담당)

### 1. `$imagegen` 호출 여부 확인 — 다른 작업보다 먼저

```bash
python3 -c "
from PIL import Image; im=Image.open('assets/img/posts/best-llm-2026-cover-raw.png').convert('RGB')
n=len(im.getcolors(maxcolors=999999) or [])
print(im.size, n, 'colors', '→ OK' if n>5000 else '→ 코드 렌더. 폐기하고 재생성')"
```

원본 PNG 기준 5,000색 미만이면 코드 렌더다. 정규화하지 말고 폐기한다.

### 2. 정규화 — 2048×1152 → 1200×630 JPEG

```bash
python3 .claude/hooks/optimize_image.py assets/img/posts/best-llm-2026-cover-raw.png --cover \
    -o assets/img/posts/best-llm-2026-cover.jpg
rm assets/img/posts/best-llm-2026-cover-raw.png
git rm assets/img/posts/best-llm-2026-cover.png
```

### 3. frontmatter 교체

```yaml
image:
  path: /assets/img/posts/best-llm-2026-cover.jpg
  alt: "A single thick glass lens element standing on dark stone, throwing a soft pool of cyan light across the surface"
```

현재 alt(`Four operational checks narrow LLM choices…`)는 이전 규칙의 **데이터 주장**이다.
클래스 A의 alt는 장면 서술이어야 하므로 교체한다. `last_modified_at`도 갱신한다.

### 4. 육안 검수 — 훅이 잡지 못하는 항목

`Read` 툴로 이미지를 직접 연다.

- 값으로 읽히는 요소가 있는가 — 셀 수 있는 반복, 눈금, 축, 읽히는 계기판 (P6)
- §6 AVOID 금지 소재가 들어갔는가 — 로봇·사람·뇌·회로기판·홀로그램 HUD·구워진 텍스트
- 상하 크롭 후에도 피사체가 온전한가
- 캐스틱 광원이 여러 갈래 띠로 갈라지지 않았는가

### 5. 최종 검증

```bash
python3 .claude/hooks/image_validation.py --report
```

`best-llm-2026`이 `OK`여야 한다.
